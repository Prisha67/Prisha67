## Research Work

**Multidimensional Evaluation of Quantized Open-Weight LLMs for Medical Question Answering**

Investigating how model quantization affects predictive performance, answer stability, confidence reliability, and computational efficiency in medical question-answering tasks.

- Evaluation across FP16, INT8, and NF4 precision configurations.
- Experiments using MedQA and MedMCQA datasets.
- Analysis of prediction changes and confidence calibration.
- Exploration of confidence-based selective screening.

*Research manuscript in progress.*
